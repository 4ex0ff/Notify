# Notify

**Notify** — это кроссплатформенное локально-ориентированное приложение для ведения заметок и управления задачами на базе Kanban-досок.

### Ключевые принципы
* **Автономность:** Все данные хранятся локально на устройстве пользователя в открытых и читаемых форматах. Приложение работает без обязательного подключения к сети.
* **Модульность и кастомизация:** Базовый функционал строится на проверенных библиотеках экосистемы Flutter с кастомной доработкой отдельных интерфейсных компонентов под задачи приложения.

---

## Технологический стек

* **Фреймворк:** Flutter (Dart)
* **Управление состоянием:** `flutter_riverpod`
* **Текстовый редактор (Rich Text):** `flutter_quill`
* **Дерево файлов:** `flutter_fancy_tree_view`
* **Канбан-доски:** `boardview`, `kanban_board`
* **Иконки:** `lucide_icons_flutter`
* **Локализация:** `flutter_localizations`
* **Работа с файловой системой:** `path`, `path_provider`, `watcher`

---

## Архитектура хранения и файловая структура

Все данные хранятся локально в единой корневой директории `NotifyStorage`.

```text
NotifyStorage/
├── notes/                   # Раздел заметок
│   ├── Проекты/            # Вложенные папки
│   │   └── идеи.json        # Файл заметки
│   └── список.json
└── tasks/                   # Раздел задач
    ├── Работа.json          # Файл канбан-доски (колонки и отдельные задачи внутри файла)
    └── Личное.json
